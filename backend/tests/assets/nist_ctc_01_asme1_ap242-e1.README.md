# NIST AP242 PMI regression fixture

Public NIST CTC 01 sample from the NIST MBE PMI Validation and Conformance
Testing project. Compressed without changing its bytes. This fixture detects
modern XDE annotations that the legacy DimTol collection omits.

- Source: https://www.nist.gov/document/nist-pmi-step-files
- Archive: https://www.nist.gov/system/files/documents/noindex/2024/06/19/NIST-PMI-STEP-Files.zip

- Member: `NIST-PMI-STEP-Files/nist_ctc_01_asme1_ap242-e1.stp`
- Member SHA-256: `85a5752da05f53c456ca3a9e038c90358e1d5a3141d1f0d6e5f0970f2356e821`

The source archive describes AP242 files as containing graphical and semantic
PMI, and cautions that these are test files with known conformance errors,
not error-free reference models. This fixture is public test evidence and does
not imply NIST endorsement or customer validation.
