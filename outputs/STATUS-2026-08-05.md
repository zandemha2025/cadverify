## 2. What the platform can honestly claim (per truth audit + PR evidence)

- **Built/proven locally:** deterministic DFM + glass-box should-cost engine (provenance-tagged, `unit_cost == Σ line_items`), STEP (mesh-level) ingestion, batch ZIP pipeline, org tenancy/RBAC/audit, SAML JIT group mapping, RFQ evidence packages, notifications inbox, cost-decision governance, Design Studio CAD generation (stack), dual-plane config boundaries, backup/restore + migration drills in CI.
- **Apparatus only (not live-certified):** SAML vs a real IdP, SCIM lifecycle, offline-CSV "integrations" (not live SAP/PLM), RFQ packages (local bundles, no supplier send), validated cost accuracy (needs real actuals).
- **Disabled/honest 501s:** S3 batch input, SAM-3D, image-to-mesh without opt-in, AP242/GD&T B-rep (mesh path only).
- **Non-negotiable invariant held throughout:** `validated=true` is only earned from real-world data — synthetic evidence cannot set it.

**Infrastructure:** domain/DNS/TLS; real production+staging Postgres, Redis, S3, Sentry, Resend, Turnstile; separate staging apps; protected GitHub deployment environments with independent approvers.

**Evidence (human gates):** G1 Zoox demo (`outputs/validation-packet.md` ready) · G2 ≥30 human routing labels (`/label` tool live over 667-part corpus) · G3 real shop quotes into the accuracy harness · supplier-quote holdout satisfying the documented gate · G4 non-additive corpus parts.
